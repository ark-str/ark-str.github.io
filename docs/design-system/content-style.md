# Content Style

## Voice

The interface should read like a calm archive guide:

- composed
- precise
- literary without becoming florid
- helpful without sounding like framework boilerplate

## UI Copy Rules

- prefer short directional labels over marketing copy
- avoid hype language, gamified rewards language, and generic dashboard labels
- empty states should explain what unlocks the next piece of information

## Summary Rules

- summarize facts and emotional direction, not fan-fiction reinterpretations
- keep chronology clear
- do not fabricate dialogue
- identify where information comes from when the UI benefits from it

## Reader Tone

- narration support text should be quiet and secondary
- dialogue support text should not compete with the actual script
- character facts should sound archival, not encyclopedic
